# Product and scope
Seebrook is an HOA-focused mobile app with three MVP modules: Membership & Accounts, Document Library, Dues & Payments.

## Pilot constraints
- Channel Harbor HOA: 32 units, currently no co-owned properties.
- Future-ready for multiple owners/property and multiple HOAs/account, without implementing unnecessary pilot UI.
- Initial administrative tasks through authenticated backend scripts/commands.
- Backend financial administration portal expected **before additional HOAs** join.
- Native iOS/Android preferred; Kotlin Multiplatform is a candidate, not a locked decision.

## Pilot outcomes
1. Invite verified owners, sign in, see assigned property.
2. View, search, download and share HOA PDFs.
3. View accurate property dues balances and transaction history imported from Excel/CSV.
4. Later, make one-time and recurring secure payments.

## Defer
Announcements, discussions, maintenance requests, full admin portal, advanced PDF management, general-ledger accounting, dispute-management UI, HA/multi-region infrastructure, automatic multi-HOA onboarding.
